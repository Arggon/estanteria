# ADR 0001 — Go como lenguaje del proyecto

- **Status:** Accepted (2026-09-14)
- **Context:** estanteria arranca como CLI personal; formaliza la decisión informal de `docs/DECISIONS.md` (archivada en `backup/2026-09-14/`).
- **Decision:** todo el proyecto en Go, versión estable vigente (1.27.1 al 2026-09-14, playbook en `docs/playbooks/go.md`).
- **Consequences:** binario estático único (cero runtime en las máquinas donde se usa), stdlib suficiente (JSON, HTTP, testing). Alternativas descartadas: Python (interpreter + venv por máquina) y Rust (costo de iteración injustificado para un CLI de ~500 líneas). Los upgrades de Go se gestionan vía refresh del playbook.
